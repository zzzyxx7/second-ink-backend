自动测试使用隔离临时数据；默认数据库当次没有业务记录，因此历史数据保留的非空样本证据来自迁移回归测试。v0.1 样本包括账号、会话、附件、文档、回执与运行，并由三个进程并发迁移；v0.3 TEAM 样本验证冻结输入、检查点 JSON／摘要不变，已有模型调用计入根预算。

新增测试重点：

- 周报与入职均完成字段修正、分支复验；与独立完整核验逐项比较结果。
- 新增／移除材料、同组来源冲突、活动分组变化、原始来源变化、制度／必填字段变化及材料缺失判定。
- 只读节点复用、旧检查点保守完整复验、任意稳定历史检查点和团队版本切换。
- 分支命令幂等、不同命令并发只成功一次、跨组织及角色隔离。
- 预览过期、输入／控制／定义／模型配置变化、检查点和原件摘要损坏。
- 独立新进程接管子分支，历史数据保留，旧草稿／确认不能发布。
- 旧 PENDING 提案失效、迟到响应丢弃、多次历史分支共享累计模型预算。
- 原有模型成功、超时、429、结构与证据校验、取消、续租及租约失效回归。

所有模型测试使用本地 HTTP 协议桩，不代表真实模型效果。MySQL 的真实连接、DDL 迁移、事务及并发仍待专用测试库就绪后验证；真实模型的语义质量、兼容性和费用另行验收。
